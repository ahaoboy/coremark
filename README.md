# CoreMark

A Rust port of the [EEMBC CoreMark](https://github.com/eembc/coremark) 1.0 benchmark.

The algorithms mirror the reference C implementation (`core_list_join.c`, `core_matrix.c`,
`core_state.c`, `core_util.c` and the `core_main.c` framework) so the reported CRCs match
bit-for-bit.
